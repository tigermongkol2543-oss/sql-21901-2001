ชื่อตาราง: product
คำอธิบาย: เก็บข้อมูลสินค้าในร้านค้า

ส่วนที่ 1 โครงสร้างตาราง
คอลัมน์ที่ 1: product_id ; รหัสสินค้า ; ตัวอย่าง P001 ; คีย์หลัก=ใช่
คอลัมน์ที่ 2: product_name ; ชื่อสินค้า ; ตัวอย่าง น้ำดื่ม ; คีย์หลัก=ไม่ใช่
คอลัมน์ที่ 3: price ; ราคาต่อหน่วย ; ตัวอย่าง 10 ; คีย์หลัก=ไม่ใช่
คอลัมน์ที่ 4: stock ; จำนวนคงเหลือ ; ตัวอย่าง 50 ; คีย์หลัก=ไม่ใช่

ส่วนที่ 2 ตัวอย่างข้อมูล
แถวที่ 1: product_id=P001 ; product_name=น้ำดื่ม ; price=10 ; stock=50
แถวที่ 2: product_id=P002 ; product_name=ขนมปัง ; price=15 ; stock=20
แถวที่ 3: product_id=P003 ; product_name=นมกล่อง ; price=12 ; stock=35

ส่วนที่ 3 เหตุผลที่เลือกคีย์หลัก
เลือก product_id เพราะสินค้าแต่ละชิ้นมีรหัสไม่ซ้ำกัน ส่วนชื่อสินค้าอาจซ้ำได้
